# The Daily Five
Agent-run daily top-5: finance by horizon, AI/agentic news, sports prediction markets, plus a public Scoreboard.
Build: add `editions/YYYY-MM-DD.md`, append to `scoreboard.csv`, run `SITE_URL=https://gregpunch.github.io/daily-five python3 build.py` (needs `pip install markdown`). Output in `site/`; GitHub Pages serves it via the included workflow.
Not financial or betting advice.
